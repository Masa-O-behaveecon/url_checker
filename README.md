# URL Checker

公開する記事のURLが命名規則に従っているかを自動チェック・編集するためのデスクトップアプリケーションです。

## 主な機能

1. **URLチェック機能**
   - 貼り付けたURLの最下層が日付（`YYYY-MM-DD`）になっているかをチェックし、不備がある場合は警告表示します。
   - URLパラメータを解析し、変数と値を表形式で分かりやすく一覧表示します。
2. **URLパラメータ編集機能**
   - パラメータの値をComboBoxから選択して自動でURLを書き換えることができます。
   - 変数の追加・削除・編集が可能です。
3. **設定管理機能**
   - パラメータ設定をローカルのJSONファイルに永続化し、次回起動時にも引き継ぎます。

---

## 📥 実行ファイル（.exe）のダウンロード

ビルド済みのWindows用実行ファイル（`URLChecker.exe`）は、**`release` ブランチ** に格納されています。

- **ダウンロード方法**:
  1. GitHub上のリポジトリページで、ブランチを `master` から **`release`** に切り替えます。
  2. `URLChecker.exe` をダウンロードしてそのまま実行できます（Python環境不要）。

---

## 🛠 開発環境・技術スタック

- **言語**: Python 3.11+
- **UIフレームワーク**: CustomTkinter
- **ビルドツール**: PyInstaller

### 🍎 Macユーザ向けビルド方法（単一ファイル形式）

Mac環境でソースコードから単一の実行ファイルをビルドする場合は、以下のコマンドを実行してください：

```bash
pip install pyinstaller customtkinter
pyinstaller --onefile --windowed --name URLChecker main.py
```
ビルド完了後、`dist/` フォルダ内に単一の実行ファイルが生成されます。同じ階層に `settings.json` を配置して運用・共有できます。
